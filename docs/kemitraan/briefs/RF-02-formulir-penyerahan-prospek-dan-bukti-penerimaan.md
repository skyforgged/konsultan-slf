> Draf kerja. Redaksi persetujuan calon klien perlu ditinjau hukum (UU 27/2022). Formulir ini dilampirkan pada perjanjian referral (RF-01) dan menjadi dasar atribusi (RF-03) dan komisi (RF-04).

## 1. Prinsip

- Mitra hanya mengirim data calon klien yang sudah **menyetujui dihubungi** oleh perusahaan.
- Kirim data seminimal mungkin: tidak ada dokumen, foto, atau data identitas.
- Setiap pengenalan menghasilkan **bukti penerimaan** dengan nomor dan waktu. Tanpa bukti penerimaan, pengenalan tidak dianggap tercatat.

## 2. Bagian A: data penyerahan (diisi mitra)

| Kolom | Wajib | Catatan |
|---|---|---|
| Nama mitra dan kontak | Ya | |
| Tanggal dan jam pengenalan | Ya | |
| Nama calon klien (orang atau badan) | Ya | |
| Kontak calon klien (satu saluran cukup) | Ya | |
| Kota dan jenis bangunan | Ya | Misalnya ruko, gudang, hotel; tanpa alamat rinci pada tahap ini |
| Kebutuhan yang diketahui | Tidak | SLF, PBG, perpanjangan, atau belum tahu |
| Hubungan mitra dengan calon klien | Ya | Kenal langsung, rekan usaha, komunitas, lainnya |
| Bukti pengenalan | Ya | Tangkapan pesan atau catatan yang menunjukkan calon klien setuju dihubungi |
| Pernyataan mitra | Ya | Teks bagian 3 |

## 3. Pernyataan mitra (draf untuk ditinjau hukum)

"Saya menyatakan bahwa calon klien di atas telah mengetahui dan menyetujui kontaknya diberikan kepada PT Zof Engineering Indonesia untuk dihubungi mengenai layanan pendampingan SLF/PBG. Saya tidak menjanjikan harga, waktu, atau hasil kepada calon klien."

## 5. Templat pesan WhatsApp untuk mitra

"Pengenalan calon klien. Mitra: ... Calon klien: ... Kontak: ... Kota/jenis bangunan: ... Kebutuhan: ... Calon klien sudah setuju dihubungi: ya. Bukti: (lampirkan)."

Balasan perusahaan: "Diterima. Nomor lead: ... Waktu: ... Status: ..."

## 6. Larangan pada penyerahan

- Mengirim daftar kontak massal tanpa persetujuan masing-masing.
- Mengirim data pribadi sensitif atau dokumen bangunan lewat formulir ini.
- Mengirim ulang calon klien yang sama di luar masa yang diatur RF-03 tanpa informasi baru.

## 7. Penyimpanan

Data disimpan sesuai UM-09, dengan akses terbatas pada penanggung jawab prospek. Mitra tidak menyimpan salinan di luar kebutuhan pelaporan.
